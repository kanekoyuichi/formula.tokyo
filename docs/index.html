事業内容

つくるところから、
届けるところまで。

相談は、たいてい「こういうシステムがほしい」「こんなコンテンツを作ってほしい」という形で届きます。けれど話を聞いていくと、本当に困っていることはその少し手前にある場合が少なくありません。

だから、できるだけ現場の近くに身を置くようにしています。実際に使う人の隣で、いつもの作業を見せてもらう。資料には書かれていない手間や、言葉になっていない工夫は、そこでしか見えないからです。

見えたものをもとにシステムを組み、伝えるためのコンテンツを整え、届く場所に置く。開発・制作・配信を分けずにひと続きで手がけるのは、そのほうが途中で意図がこぼれ落ちないからです。

公開したあとも、使われ方を見ながら手を入れ続けます。現場に合わせて形を変えていくところまでを、ひとつの仕事だと考えています。

大切にしていること

シンプルに、長く。

システムでもコンテンツでも、つくり始めると、あれもこれもと足したくなります。機能をひとつ増やすのは簡単ですが、増えた分だけ、説明も、手入れも、壊れる場所も増えていきます。

だから、足す前に一度立ち止まって「これがなくても成り立つか」を考えるようにしています。削ったあとに残ったものが、たいていそのプロジェクトの芯です。

Formula は「式」を意味する言葉で、F1 の「フォーミュラ」は、もとは全チームが従う規定のことを指します。華やかに見えるレースの裏側では、決められた条件のなかで空力やタイヤ、燃料、ピット戦略までが緻密に計算され、コンマ一秒が積み上げられています。条件を正しく読み、要素をひとつの式として組み立てる。仕事の進め方も、それに近いと思っています。

芯だけでできたものは、長持ちします。数年後に誰かが手を入れるときも迷わずに済み、使う人の状況が変わっても、形を変えながら使い続けられます。

派手さはなくても、気づけばずっとそこにある。そういうものをつくりたいと思っています。
